# vgraffiti

Расширение Chromium (Manifest V3): палитра и канвас для рисования поверх Google Maps и Яндекс.Карт. Сервер и вход не используются.

Техническое описание продукта (если актуально): [`docs/tz.md`](docs/tz.md).

## Разработка

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

В Chrome: **Расширения → Режим разработчика → Загрузить распакованное** — указать папку `.output/chrome-mv3` (путь покажет WXT в консоли после `dev`).

## Сборка

```bash
npm run build
npm run zip
```

## Использование

Откройте страницу карты (см. домены в манифесте) — справа сверху появится панель: инструменты, палитра, отмена/повтор.

## Стек

- [WXT](https://wxt.dev/) + TypeScript
